# Colour and behaviour

The analyser normalises the catalogue — and organises the metre it standardises.

An em dash — right before travelling — shifts every byte offset after it.

The `phpstan-analyse` tool is named after the flag, so the spelling inside it is covered.

A bare analyse here is allowed, because the literal names this line.

A bare analyse here is not, because the literal names line nine only.

A synthetic analysoid keeps this test independent of the shipped suffixes.
