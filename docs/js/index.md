# ☕ JS

The JavaScript half of **@brnshkr/config**: a strict, bundler-first TypeScript base plus two flat-config builders that lazily activate every supported plugin you actually have installed. Per-tool pages below; the [README](../../README.md#-js) covers setup.

- [ESLint](./eslint/index.md) — flat-config builder + the custom `brnshkr` plugin rules
- [Stylelint](./stylelint.md) — config builder with installable, auto-detected modules
- [TypeScript](./typescript.md) — strict, bundler-first `tsconfig.json` base
