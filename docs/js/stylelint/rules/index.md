# 🧩 Custom Stylelint rules

All rules ship as `brnshkr/<rule>` and are enabled by the default configuration unless the `brnshkr` option is `false`.

## Code

- [`brnshkr/fenced-code`](./fenced-code.md)
  — with the `markdown` module, stylesheet code blocks in Markdown pages and docblocks
  are linted like files of their dialect
